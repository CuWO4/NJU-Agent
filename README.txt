njuagent

一、项目简介

njuagent 是一个从零构建的编程智能体（coding agent），以桌面应用形式交付。
它直接调用 DeepSeek 的对话补全接口，自主完成读写文件、执行命令、检索代码等
编程任务。整个智能体核心——模型输出的结构化流式解析、工具调用循环、会话与
上下文管理、终止与重试策略——均由本项目自行实现，未封装任何现成的 agent
框架或厂商 SDK；配套的三栏工作台界面经 Electron 封装为本地桌面应用。

项目远程仓库：https://github.com/CuWO4/NJU-Agent

二、编译与运行

构建桌面端需要 Python 3.10 或更高版本。需要先安装根据项目虚拟环境描述, 安装
python 和 npm 依赖。然后在项目根目录运行一键构建脚本：

    python build.py

产物为绿色目录 electron/dist/win-unpacked 与便携单文件，直接运行即可，无需
安装 Python 环境。API Key 在应用欢迎页的 Settings 中设置，由应用统一管理并
注入后端；打开或切换工作区后即可开始使用。

三、特色功能

1. 计划模式：启用后 agent 先给出执行计划而不改动文件，待确认后再实施。

2. 动态 SKILL：在工作区 .njuagent/skills 目录放置 .md 提示词文件，会自动注入
系统提示词，按需定制 agent 行为。

3. 多 agent 并行：以独立上下文并行拉起多个子 agent 完成子任务并汇总结果；
子 agent 默认被拒绝执行需审批的操作。

4. 上下文管理：按模型返回的真实 token 用量，在完整回合边界处压缩早期历史；
支持编辑历史用户消息并回拉会话到该节点重新执行。

5. 审批与安全：命令执行与工作区外文件操作需显式审批，工作区内文件操作免
审批；提供会话级自动审批开关；文件修改以快照记录为待定变更，可逐项保留或
回滚；命令支持超时与中断。

6. 会话持久化：会话消息、待定修改快照与设置持久化于 .njuagent，进程重启后
完整恢复，对话可跨进程延续。

7. 文件管理：可通过目录树看到工作区状态，并通过编辑区读写编辑文件。

8. Git 与搜索侧边栏：查看仓库状态与分支、填写提交信息完成提交（未初始化
时可一键初始化仓库）；全局搜索支持大小写、全字与正则匹配，结果可点击定位。

9. 编辑与呈现：Markdown 渲染；对话代码块与文件编辑器语法高亮；工具调用以
面向用户的方式渲染（显示名与参数值）；实时流式输出、思考过程折叠。

10. 桌面工作区管理：使用 Electron 包装为桌面端应用。
